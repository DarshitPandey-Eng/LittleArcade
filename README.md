# Little Arcade

Little Arcade is a simple browser-based mini-games website built using HTML, CSS, and JavaScript.

The idea behind this project was to bring a few classic games together in one place with a clean and easy-to-use interface. The website works on both desktop and mobile devices and includes a light and dark theme.

## Games Included

**1. Tic-Tac-Toe**

A two-player game where players take turns placing X and O on a 3×3 grid. The first player to complete a row, column, or diagonal wins.

**2. Rock Paper Scissors**

Play against the computer. The computer randomly selects rock, paper, or scissors, and the result is displayed after each round.

**3. Number Guess**

Guess a randomly generated number between 1 and 100. The game gives hints to help you find the correct number.

**4. Memory Match**

Flip cards and try to find matching pairs. The goal is to match all the cards using as few moves as possible.

**5. Reaction Test**

Test your reaction speed by clicking at the right moment. The game measures your response time in milliseconds.

**6. Quick Math**

Solve randomly generated arithmetic questions and check how many you can answer correctly.

## Features

- Six playable mini-games
- Clean and responsive user interface
- Light and dark mode
- Desktop and mobile support
- Score and result displays
- Restart options for each game
- Basic input validation
- No login or account required
- Works offline

## Technologies Used

- **HTML5:** Structure and content of the website
- **CSS3:** Styling, layout, animations, and responsive design
- **JavaScript:** Game logic, user interactions, scoring, and theme switching

The project uses plain HTML, CSS, and JavaScript without any external frameworks or libraries.

## How to Run

1. Download or clone this repository.
2. Extract the files if downloaded as a ZIP.
3. Open the project folder.
4. Open `index.html` in a web browser.
5. Select a game and start playing.

No additional installation or server is required.
